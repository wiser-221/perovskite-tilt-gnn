# Step 4—6：角度畸变形成能预测

当前状态：1599个候选与CHGNet代理标签、五个形成能基础模型和五个双图差分模型均已完成。双图模型已通过角度留出验证及一次性封存测试；结果是CHGNet代理精度，不是DFT精度。

## 方法与检查

从原测试独占组成中排除旧30个研究组成后固定选择100个组成。角度任务在每个组成内部按畸变幅度留出：999个训练池、200个验证、400个封存测试，三者均覆盖100个组成，测试目标是已知组成的角度插值。原始形成能数据仍按约化组成严格隔离，防止迁移权重污染其验证和测试。

原始形成能划分为51923训练、4217验证、3568测试记录；角度数据为999训练、200验证、400测试结构。候选结构去重、BO6六配位及最短距离检查已通过。

实际采用原生共享氧Glazer生成器，并非PySPuDS。每条生成扫描采用固定体积与rocksalt排序，两个模式、2—14度名义幅度；实际角度另行记录。共享氧平均处理会伴随键长改变。数据集母体和生成扫描的晶胞形状/排序可能不同，因此两者能差不能全部归因于角度。

形成能基础模型读取原始`formation_energy_per_atom`，重新初始化输出头，重算训练集标准化量。已验证缓存分解能标签不会被错误沿用。

CHGNet只做固定几何单点计算，代理标签是原始母体形成能加上候选与同一原始母体的CHGNet每原子能量差。新增标签明确为代理值，不是DFT真值。

主动学习使用“冻结形成能基础GNN + 零初始化AngleGNN残差支路”，并联合优化三项损失：原始形成能样本上的零残差约束、较低权重的CHGNet代理绝对形成能、较高权重的同组成扫描能量差。角度差损失只比较固定晶格和排序的生成结构，不把晶胞/排序不同的原始母体混入角度指标；母体只负责把代理能标尺锚定到原始形成能。比较主动与随机策略，在相同初始样本和预算下使用3个采样随机种子。每个预算从形成能基础模型适配，避免混淆累积训练量和样本量。全池标签预计算后隐藏未查询值，属于离线主动学习实验。

## 验收

验证集成对MAE≤0.01 eV/atom，平均regret≤0.01 eV/atom，原始形成能MAE退化不超过5%。不确定性先采用低分歧50%结构对作为覆盖要求，检查其误差≤0.01及分歧与误差正相关；独立测试使用验证集冻结的阈值，不重新调节。

达到预算上限不等于完成目标。只有验证达标才打开独立测试；若未达标，报告原因并根据学习曲线决定扩充，不自动降低阈值。

## 资源与运行记录

单进程、2个CPU计算线程、BF16训练；GPU状态每10秒写入数据库。首次32结构前向/反向测试峰值分配显存约602 MiB。原有7项测试加4项新回归测试共11项通过；新数据划分、形成能标签替换及指标解析检查通过。

前两个epoch使用batch size 32，每轮约105秒。随后在断点处暂停，测量32/64/96批量的短时纯训练吞吐，分别约580/806/932结构每秒，峰值分配显存约616/1204/1805 MiB；据此改为96并继续。此吞吐不含完整数据读取和验证时间，不能直接用来估算完整epoch。前两轮验证MAE为0.03039、0.02924 eV/atom，仍处于基础训练阶段。

第一版主动学习仅拟合绝对代理能：预算280与560使用1e-5学习率，成对MAE由0.08851降至0.08241 eV/atom；从预算840起提高到1e-4后，全池1119个标签仍只有0.07655 eV/atom，形成能MAE还退化18.6%。这证明问题不是继续增加标签即可解决。该失败结果保留在运行记录中作为诊断证据，正式流程已改为直接训练同组成扫描能量差，并排除母体晶胞/排序差对角度指标的污染。

第二版直接成对微调仍因形成能退化而被早停退回基础模型；第三版冻结基础模型后发现，完全未见组成的验证实际上考查跨化学空间外推，并不对应本项目的角度插值目标。正式第四版采用组成内角度留出与冻结基础模型的残差支路；早期单seed验证扫描MAE已由约0.069降到约0.042 eV/atom，但尚未达到0.01，不能提前宣称完成。

最终采用双图差分：同一个AngleGNN编码器分别处理候选结构和同组成立方参考，差分头学习CHGNet的每原子能量差；原形成能MLP继续提供参考能量基线，新增锚点头只校准人工参考结构。99个组成使用立方参考；1个组成因立方与母体重复被去重，使用最小幅度生成结构作为参考。五种子集成验证集的绝对代理形成能MAE为0.00355、候选相对参考的差分MAE为0.00305 eV/atom；封存测试集分别为0.00611和0.00589 eV/atom，测试P90差分误差0.01383，不确定性—绝对误差Spearman相关系数0.451。

为排除指标定义改变造成的虚假提升，又按旧单图流程完全相同的“同组成内所有留出结构两两能量差、再按组成平均”口径复算：双图模型验证pair MAE为0.00530、封存测试pair MAE为0.00911 eV/atom；旧单图模型约为0.075。因此提升并非只来自改名或单位变化。划分审计显示训练/验证/测试候选ID以及`(组成,模式,角度)`均无重叠，但100个组成有意共享；结论仅适用于已知组成上的未见角度插值，不能解释为新组成外推。上述均为对CHGNet代理标签的误差，不是相对真实DFT的误差。

训练峰值分配显存约1.90 GiB，稳定阶段每epoch约2.5—2.8秒。五个模型以seed 42、123、2026、3407、7777统一打包在`step6/models.pt`，同一份也保留为`dual_models.pt`。

旧Step 6约18 MB代理实验结果及模型已按用户要求删除，未单独备份；原Step 4/5受Git跟踪的旧结构和评分文件可从版本历史恢复。原始数据和原始五模型保留。
