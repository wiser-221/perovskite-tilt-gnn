# 步骤4：同组成多晶型生成

每个步骤3组成统一生成11个结构，共330个CIF：

```text
1个MP原始母结构
1个a⁰a⁰a⁰零倾斜结构
4种非零倾斜 × 6°/12°
1个A/B位排序对照
= 11个/组成
```

## Glazer倾斜

旋转对象是以B阳离子为中心的BO₆八面体，B近似保持在中心，周围O原子按周期相位移动。共享氧的位置取相邻两个八面体旋转后位置的平均，并检查BO₆六配位和实际B–O–B角。

| 模式 | x轴 | y轴 | z轴 | 含义 |
|---|---:|---:|---:|---|
| `a⁰a⁰c⁻` | 0° | 0° | ±6°/±12° | 仅z轴反相旋转 |
| `a⁻a⁻a⁻` | ±6°/±12° | ±6°/±12° | ±6°/±12° | 三轴均反相旋转 |
| `a⁻a⁻c⁺` | ±6°/±12° | ±6°/±12° | 同相6°/12° | x、y反相，z同相 |
| `a⁰a⁰c⁺` | 0° | 0° | 同相6°/12° | 仅z轴同相旋转 |

`+`表示相邻八面体同方向旋转，`−`表示相邻八面体反方向旋转，`0`表示不旋转。

`a⁰a⁰a⁰`没有实际旋转角，因此只生成一个零倾斜结构，不把它虚构成6°和12°两个不同结构。

## A/B位排序对照

基准结构使用岩盐型A/B排序；排序对照只改变A或B阳离子的空间排列（优先使用层状排序），不改变倾斜角度。它用于区分形成能变化来自八面体倾斜还是阳离子排序。

## 输出与验证

- `candidates/`：330个CIF；
- `candidate_manifest.csv`：倾斜模式、名义角度、排序方式、空间群、实际B–O–B角、B–O键长和文件路径。

程序检查组成、BO₆六配位、最短原子距离，并用 `StructureMatcher` 去重。这些结构是AngleGNN筛选和DFT松弛的初始构型，不代表已证明稳定。
