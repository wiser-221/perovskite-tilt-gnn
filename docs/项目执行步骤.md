# Perovskite Tilt GNN 项目执行步骤

## 核心科学问题

> 角度感知 GNN 能否识别钙钛矿八面体倾斜和阳离子排序引起的能量变化，并通过 DFT 主动学习发现更低能多晶型？

## 阶段一：固定实验基础

### 1. 数据完整性审计

输入：

```text
dataset/processed/perovskites.csv
dataset/processed/structure_index.csv
dataset/raw/structures/
dataset/processed/random_split.csv
dataset/processed/ood_a_pair_split.csv
```

执行：

- 检查 59,708 条标签与结构一一对应；
- 检查重复结构、缺失结构和异常能量；
- 统计组成类型、元素和分解能分布；
- 确认训练、验证、测试之间没有重复结构；
- 固定数据版本和文件哈希。

输出：

```text
data_audit.csv
dataset_manifest.json
```

验收：

```text
缺失结构 = 0
重复 material_id = 0
数据划分重叠 = 0
```

### 2. 锁定统一实验协议

固定：

```text
目标：decomposition_energy_per_atom
随机种子：42、123、2026
数据划分：random_split.csv
OOD 划分：ood_a_pair_split.csv
早停指标：validation MAE
评价指标：MAE、RMSE、R²、PR-AUC
近稳定阈值：0.05 eV/atom
```

所有模型使用相同划分、随机种子和评价程序。

输出：

```text
experiment_config.yaml
```

## 阶段二：建立角度感知 GNN

### 3. 构建角度图数据

对每个晶体生成：

```text
节点：原子序数
边：周期性邻接关系、距离、径向基
三体：j—i—k 索引、cosθ、角度基
```

重点标记：

```text
B—O—B
O—B—O
A—O—B
```

同时计算：

```text
平均 B—O—B 角
B—O—B 角标准差
BO6 键长畸变
BO6 角度畸变
```

输出：

```text
graph_cache.pt
geometry_descriptors.csv
```

验收：

- 周期性邻居正确；
- 晶体整体旋转后距离、夹角及预测不变；
- 改变内部氧原子位置后角度特征发生变化；
- 不存在无邻居原子和非法三体。

### 4. 实现三种对照模型

统一实现：

1. 成分模型：元素、氧化态和容忍因子；
2. 距离 GNN：原子种类和距离；
3. 角度 GNN：原子种类、距离和夹角。

角度 GNN 结构：

```text
原子图消息传递
+
键线图或三体消息传递
+
晶体池化
+
分解能回归头
```

输出：

```text
composition_baseline.py
distance_gnn.py
angle_gnn.py
```

### 5. 完成模型单元测试

测试：

- 输入输出张量形状；
- 周期性邻居和夹角计算；
- 旋转不变性；
- batch 拼接；
- 梯度反向传播；
- 同一结构旋转前后预测一致；
- 不同倾斜结构不能产生完全相同的图表示。

所有测试通过后才能开始正式训练。

## 阶段三：基础数据训练与比较

### 6. 训练三个角度 GNN

随机种子：

```text
42
123
2026
```

建议起始配置：

```text
hidden_dim = 128
layers = 4
batch_size = 8～16
max_neighbors = 16
mixed_precision = true
gradient_accumulation = 2～4
```

保存：

```text
best_model.pt
training_history.csv
validation_predictions.csv
test_predictions.csv
```

### 7. 公平比较三种模型

比较：

- 测试集 MAE、RMSE 和 R²；
- OOD 测试误差；
- 近稳定分类 PR-AUC；
- 不同分解能区间误差；
- 不同组成类型误差；
- 参数量、训练时间和显存；
- 三模型集成均值与标准差。

角度消融：

```text
距离 GNN
距离 + B—O—B
距离 + 全部三体角
完整角度 GNN
```

这一阶段只能回答显式角度是否改善总体分解能预测，不能宣称模型已经具有多晶型排序能力。

进入下一阶段的条件：

- 角度 GNN 训练稳定；
- 测试性能不低于距离 GNN；
- 角度消融显示角度分支确实参与预测。

## 阶段四：建立多晶型测试集

### 8. 选择并冻结研究组成

选择 25～30 个组成：

```text
开发组成：约 20 个
盲测组成：5～10 个
```

覆盖：

- 接近稳定阈值；
- 中等分解能；
- 高不确定性；
- 稳定正对照；
- 不稳定负对照；
- 不同元素、组成类型、容忍因子和磁性。

在生成结构和 DFT 前固定：

```text
development_compositions.csv
blind_compositions.csv
```

盲测组成不得参与调参和主动学习。

### 9. 生成候选多晶型

使用：

```text
PySPuDS
pymatgen
enumlib
StructureMatcher
```

每个组成生成约 10 个结构，覆盖：

```text
a⁰a⁰a⁰
a⁰a⁰c⁻
a⁻a⁻a⁻
a⁻a⁻c⁺
a⁻b⁺a⁻
A/A′ 排序
B/B′ 排序
```

执行：

- 生成结构；
- 检查化学计量、电荷和占位；
- 排除原子重叠；
- 使用 StructureMatcher 去重；
- 记录生成参数；
- 将原始数据结构加入候选集合。

输出：

```text
约 300 个候选 CIF
candidate_manifest.csv
```

验收：

- 每个候选组成保持不变；
- 所有结构可被 pymatgen 读取；
- 无重复结构；
- 无明显原子重叠。

## 阶段五：GNN 筛选与第一轮 DFT

### 10. 角度 GNN 预测候选

三个角度 GNN 对全部候选预测：

```text
绝对分解能
集成平均值
模型间标准差
近稳定概率
组成内部排名
```

每个开发组成选取：

1. 原数据结构；
2. 预测能量最低结构；
3. 不确定性最高结构；
4. 一个随机结构。

输出：

```text
candidate_predictions.csv
round1_dft_selection.csv
```

### 11. 建立统一 DFT 流程

先选择 2 个组成测试 DFT 流程。

统一设置：

```text
VASP
PBE+U
ENCUT = 520 eV
自旋极化
高自旋铁磁初始化
MPRelaxSet
晶格、体积和原子位置全部优化
```

流程：

```text
relax1
→ relax2
→ static
```

检查：

- ENCUT 和 k 点密度收敛；
- 磁矩初始化；
- 力和应力收敛；
- 赝势与 U 值固定；
- 失败任务可以自动续算。

验收后冻结 DFT 参数，后续不得修改。

### 12. 第一轮 DFT 计算

规模：

```text
10 个开发组成 × 4 个结构 ≈ 40 个任务
```

每个组成必须包含重新计算的原始结构。

计算：

```text
ΔE = (E候选 − E该组成最低结构) / 原子数
```

输出：

```text
round1_dft_results.csv
优化后结构
OUTCAR/vasprun.xml
计算参数与收敛状态
```

## 阶段六：评价真正的多晶型能力

### 13. 第一轮排序评价

对每个组成计算：

```text
Spearman
Top-1 命中率
Top-3 命中率
regret
```

其中：

```text
regret = GNN选中结构的DFT能量 − 已计算结构中的最低DFT能量
```

同时统计：

- 比原结构更低能的候选数量；
- 降低超过 20～30 meV/atom 的数量；
- DFT 优化后保持钙钛矿骨架的比例；
- 预测不确定性与真实误差相关性；
- 不同倾斜和排序类型的误差。

这一阶段回答基础角度 GNN 能否泛化到训练集中不存在的同组成多晶型。

## 阶段七：DFT 主动学习

### 14. 构建多晶型训练标签

新增样本使用两类标签。

绝对标签：

```text
候选分解能
≈ 原结构分解能
+ 候选与重新计算原结构的DFT相对能量
```

成对标签：

```text
ΔEij = Ei − Ej
```

保留：

- 原 59,708 条绝对标签；
- 第一轮 DFT 结构；
- 同组成结构对；
- 开发和盲测标记。

输出：

```text
active_learning_round1.csv
polymorph_pairs_round1.csv
```

### 15. 微调角度 GNN

联合损失：

```text
L = L_absolute + λL_pair
```

执行：

- 从基础角度 GNN 权重开始；
- 降低学习率；
- 原数据与新增 DFT 数据混合采样；
- 三个随机种子分别微调；
- 完全排除盲测组成。

比较微调前后：

- 原测试集 MAE；
- 开发多晶型 Spearman；
- Top-1 和 Top-3；
- regret；
- 不确定性校准。

验收：

- 多晶型排序性能提高；
- 原测试集性能不能明显退化。

### 16. 第二轮主动学习

使用微调模型预测剩余开发候选。

每个组成同时选择：

```text
利用：预测能量最低
探索：高不确定性且结构差异最大
```

增加约 30～40 个 DFT 任务：

```text
第二轮DFT
→ 更新训练集
→ 第二次微调
→ 再次评价
```

记录：

- 每轮新增 DFT 数量；
- 新低能结构数量；
- 排序指标改善；
- 单位 DFT 任务带来的性能提升。

## 阶段八：独立盲测

### 17. 解封盲测组成

主动学习和模型选择全部结束后，才使用盲测组成。

比较：

```text
随机选择
距离 GNN
基础角度 GNN
主动学习角度 GNN
```

主要指标：

- Spearman；
- Top-1 和 Top-3 命中率；
- 平均 regret；
- 发现更低能结构数量；
- 跨过近稳定阈值的组成数量。

盲测只运行一次，不再根据结果调整模型。

## 阶段九：最终稳定性复核

### 18. 计算最终分解能

只对最有价值的新低能结构执行：

```text
形成能计算
→ 获取竞争相
→ 能量兼容修正
→ 构建相图
→ 计算分解能
```

工具：

```text
Materials Project API
pymatgen PhaseDiagram
```

重要发现必须同时满足：

- 比重新计算的原结构低 20～30 meV/atom；
- 最终分解能明显降低；
- 优化后保持钙钛矿骨架；
- 计算参数和竞争相处理一致。

重点报告从：

```text
ΔHd > 0.05 eV/atom
```

变为：

```text
ΔHd ≤ 0.05 eV/atom
```

的候选。

4. 不确定性是否提高 DFT 采样效率；
5. 是否发现原单起点流程遗漏的低能钙钛矿结构。

## 执行约束

前 7 步完成前不开始多晶型生成。角度模型通过基础验证后，才能进入候选生成和 DFT 阶段。项目结论仅适用于已枚举的钙钛矿倾斜与阳离子排序空间，不宣称找到全部晶体结构空间中的全局最低能结构。
