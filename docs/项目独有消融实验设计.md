# 项目独有消融实验设计

## 目标

仅验证本项目特有的三项设计：三体角类型、DFT母体锚定和同组成Pair Loss。迁移学习与角度信息的一般有效性由已有研究支持，不作为本轮主要消融问题。

所有实验使用相同的数据划分、随机种子、训练轮数、优化器和模型选择规则。除被消融模块外，其余配置保持不变。

## 1. 三体角类型消融

### 要解决的问题

显式区分钙钛矿中的不同三体化学环境，是否比只输入角度数值更有利于形成能变化和倾斜构型排序？

当前模型将三体角分为：

```text
B–O–B
O–B–O
A–O–B
OTHER
```

### 对照实验

| 实验 | 角度数值 | 三体角类型 |
|---|---|---|
| Generic-angle | 使用 | 不区分，全部作为同一种角 |
| Typed-angle | 使用 | 区分B–O–B、O–B–O、A–O–B和OTHER |

### 评价指标

- 代理形成能MAE；
- 同组成相对能量ΔE MAE；
- Pair MAE；
- 最低能候选Top-1准确率；
- Regret；
- 未见组成测试结果。

### 可支持的结论

如果Typed-angle稳定优于Generic-angle，可以说明角的化学角色信息提供了超出纯几何角度数值的有效归纳偏置。

## 2. DFT母体锚定消融

### 要解决的问题

使用原始DFT母体形成能作为绝对能量锚点，并只让模型学习同组成畸变能量差，是否比直接回归候选结构的绝对代理形成能更稳定？

当前代理标签为：

```text
Ef_proxy(x)
= Ef_DFT(parent)
+ [E_CHGNet(x) - E_CHGNet(parent)]
```

其中，候选结构与母体化学组成相同，元素参考项在能量差中抵消。

### 对照实验

| 实验 | 学习方式 |
|---|---|
| Direct | 从候选结构直接预测绝对代理形成能 |
| Anchored-delta | 使用母体形成能作为锚点，模型预测候选相对母体的ΔE |

Anchored-delta最终输出：

```text
Ef_prediction(candidate)
= Ef_prediction/reference(parent)
+ ΔE_prediction(candidate, parent)
```

### 评价指标

- 原始DFT结构形成能MAE；
- 候选代理形成能MAE；
- 相对母体ΔE MAE；
- 不同组成间的误差偏移；
- 未见组成测试结果。

### 可支持的结论

如果Anchored-delta在保持原始形成能精度的同时降低ΔE误差，可以说明“DFT绝对能量锚点＋CHGNet同组成差分标签”比直接混合两种能量口径更适合当前任务。

不得将该结果表述为新候选具有DFT真值；新增角度标签仍是CHGNet代理标签。

## 3. 同组成Pair Loss消融

### 要解决的问题

在绝对形成能损失之外显式监督同组成候选之间的能量差，是否能够提高倾斜构型排序能力？

完整训练损失为：

```text
L
= L_DFT_formation
+ λproxy × L_proxy_formation
+ λpair × L_pair
```

Pair Loss约束：

```text
[Ef_pred(i) - Ef_pred(j)]
≈ [Ef_proxy(i) - Ef_proxy(j)]
```

其中，结构i和j必须属于同一化学组成。

### 对照实验

| 实验 | Pair Loss权重 |
|---|---:|
| No-pair | λpair = 0 |
| Pair | λpair = 2.0（当前配置） |

### 评价指标

- 绝对形成能MAE；
- 相对能量ΔE MAE；
- Pair MAE；
- 最低能候选Top-1准确率；
- Regret；
- 不同Glazer模式的排序结果。

### 可支持的结论

如果加入Pair Loss后绝对形成能MAE变化较小，但Pair MAE、Top-1和Regret改善，可以说明该损失主要增强了模型对同组成细小倾斜能量差的辨别能力。

## 最小实验矩阵

以当前完整模型为基准，只训练三个消融版本：

| 模型 | 三体角类型 | DFT母体锚定 | Pair Loss |
|---|---|---|---|
| Full | 使用 | 使用 | 使用 |
| Generic-angle | 不使用 | 使用 | 使用 |
| Direct | 使用 | 不使用 | 使用 |
| No-pair | 使用 | 使用 | 不使用 |

## 实验控制要求

- 使用相同训练、验证和测试结构；
- 同一组成的全部构型必须属于同一个集合；
- 使用相同随机种子；
- 使用相同训练预算和早停规则；
- 每个模型依据相同验证指标选择checkpoint；
- 最终测试集不得参与权重、阈值或超参数选择；
- 同时报告均值、标准差和失败案例，不只报告最佳种子。
