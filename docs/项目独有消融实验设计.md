# 项目独有消融实验设计

## 目标

只验证当前项目中三个直接影响结论的设计：

1. 双图差分学习是否优于单图绝对形成能回归；
2. 已有形成能模型之上是否还需要 `anchor_head`；
3. 显式区分三体角类型是否有额外价值。

不单独验证“角度信息一般是否有用”，也不设置当前代码中不存在的独立 Pair Loss 消融。

## 统一实验条件

- 使用完全相同的训练、验证和测试集；
- 数据必须按化学组成分组，同一组成的所有构型不得跨集合；
- 使用相同的5个随机种子、训练轮数、早停规则和优化器；
- 所有模型使用同一套CHGNet代理形成能标签；
- 每次只修改被消融的模块；
- 测试集不用于早停、调参或checkpoint选择。

## 1. 双图差分学习消融

### 要解决的问题

同一组成下，用“参考结构形成能＋候选与参考的能量差”预测候选结构，是否比从单个候选结构直接回归绝对形成能更准确？

### 对照

| 模型 | 输入 | 输出方式 |
|---|---|---|
| Single-graph | 候选结构 | 直接预测候选代理形成能 |
| Dual-delta | 候选结构＋同组成零倾斜参考 | 参考形成能＋预测的 `ΔE` |

这是最重要的消融，用来判断当前双图差分架构是否真正优于普通单图模型。

## 2. `anchor_head` 消融

### 要解决的问题

形成能迁移模型已经能够预测参考结构形成能时，额外的 `anchor_head` 是否真的能够校正人工零倾斜结构的域偏移？

### 对照

| 模型 | 候选形成能 |
|---|---|
| No-anchor | `candidate_norm = base_norm + delta_norm` |
| Full | `candidate_norm = base_norm + anchor_norm + delta_norm` |

`base` 在两组实验中都保持冻结，其他训练条件完全相同。

除总体误差外，还要统计 `anchor_norm` 还原到 eV/atom 后的均值、标准差和绝对值分布。如果它接近0且Full没有稳定改善，应删除 `anchor_head`。

## 3. 三体角类型消融

### 要解决的问题

在使用相同角度数值的前提下，显式区分不同局部化学环境是否改善能量差和倾斜构型排序？

### 对照

| 模型 | 角度数值 | 三体角类型 |
|---|---|---|
| Generic-angle | 使用 | 全部设为同一类 |
| Full | 使用 | 区分B–O–B、O–B–O、A–O–B和OTHER |

这项实验不是证明“角度有用”，而是检验本项目设计的角度化学类型编码是否比纯几何角度更有价值。

## 最小实验矩阵

| 模型 | 双图差分 | `anchor_head` | 三体角类型 |
|---|---:|---:|---:|
| Full | 是 | 是 | 是 |
| Single-graph | 否 | 不适用 | 是 |
| No-anchor | 是 | 否 | 是 |
| Generic-angle | 是 | 是 | 否 |

包括Full在内只需要4种模型配置。

## 统一评价指标

| 指标 | 用途 |
|---|---|
| 候选代理形成能MAE | 评价绝对能量预测 |
| 相对参考 `ΔE` MAE | 评价倾斜导致的能量变化 |
| 参考结构形成能MAE | 判断 `anchor_head` 的校正作用 |
| Spearman相关系数 | 评价同组成构型的整体排序 |
| Top-1准确率 | 评价是否找到最低能候选 |
| Regret | 评价选错构型时距真实最低能的差距 |

所有指标报告5个种子的均值和标准差，不只报告最佳种子。

## 结论规则

- 只有多个随机种子下都稳定改善的模块，才保留并宣称有效；
- 如果 `anchor_head` 没有明显改善参考能和候选形成能MAE，应删除；
- 如果双图差分只改善 `ΔE`和排序，应将其定位为构型排序模型，不宣称全面提高绝对形成能精度；
- 新角度结构的标签仍是CHGNet代理标签，不得表述为新的DFT真值。
