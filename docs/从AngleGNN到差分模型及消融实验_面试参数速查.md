# 从AngleGNN到差分模型及消融实验：面试参数速查

## 1. 一句话项目路线

先用59,708个DFT优化的多元氧化物钙铛矿训练五种子AngleGNN分解能模型，再将其迁移到DFT形成能，随后用CHGNet给1599个受控倾斜结构做固定几何单点标注，最终训练“候选结构＋同组成零倾斜参考结构”的双图差分模型，并通过三组消融检验关键设计。

## 2. 全流程速览

| 阶段 | 训练目标 | 数据 | Batch | 最大Epoch | 五种子参数是否独立 |
|---|---|---:|---:|---:|---|
| 原始AngleGNN | DFT分解能 | 47,766/5,971/5,971 | 96戒192 | 100 | 是 |
| 形成能迁移 | DFT形成能 | 51,923/4,217/3,568 | 96 | 40 | 是 |

| Generic-angle消融 | 统一所有角类型 | 800/200/400对 | 48对 | 80 | 是 |

五个随机种子均为 `42, 123, 2026, 3407, 7777`。

每层执行：

```text

```

## 4. 阶段A：原始AngleGNN分解能训练

### 任务与数据

- 输入：单个DFT优化晶体图。
- 输出：`decomposition_energy_per_atom`，eV/atom。
- 随机划分：47,766训练、5,971验证、5,971测试。
- 训练集标准化：均值 `0.168494`，标准差 `0.112575 eV/atom`。

### 训练参数

| 项目 | 值 |
|---|---:|
| 优化器 | AdamW |
| 初始学习率 | `3e-4` |
| Weight decay | `1e-5` |
| 损失 | SmoothL1，`beta=0.1` |
| 梯度裁剪 | 5.0 |
| 调度器 | ReduceLROnPlateau |
| 早停 | patience 12，min delta `1e-5` |
| 混合精度 | BF16 |
| 模型选择 | 最低验证MAE |

原始五种子分两批运行：项目保留的配置分别为 `batch/eval=96/128`和高吞吐 `192/256`。因此不应声称原始五个种子的batch完全相同；模型结构、学习率和目标一致。

## 6. 阶段C：倾斜结构与CHGNet代理标签

### 结构池

- 从原始形成能测试组成中固定选择100个组成；
- 每个组成构建母体、零倾斜参考，以及 `a0a0c-`、`a-a-a-` 两种模式的2–14°扫描；
- 理论数量1600，去重后1599个结构；
- 角度任务划分为999训练池、200验证、400留出测试；
- 双图正式训练排除母体和参考本身，最终使用800个训练对、200个验证对、400个测试对。

100个组成在三个集合中有意共享，不是未见组成外推，只是已见组成下的未见角度插值。

### 标签

CHGNet 0.3.0只做固定几何单点，不弛豫。代理形成能为：

```text
Ef_proxy(candidate)
= Ef_DFT(parent)
+ [E_CHGNet(candidate) - E_CHGNet(parent)]
```

1599个单点标注约2分钟，约13–14个结构/秒。这是CHGNet代理标签，不是新DFT真值。

## 7. 阶段D：Full双图差分模型

### 输入输出

```text
候选倾斜结构 x + 同组成零倾斜参考 r
                         ↓
候选代理形成能 + 候选相对参考的 ΔE
```

实际前向公式：

```text
candidate_norm = base_norm(r) + anchor_norm(r) + delta_norm(x, r)
```

- `base`：冻结的形成能AngleGNN，只给参考结构提供基线；
- `encoder`：可训练的共享AngleGNN，同一套参数分别编码 `x`和 `r`；
- `delta_head`：输入 `[hx-hr, |hx-hr|, hx×hr]`，预测ΔE；
- `anchor_head`：根据 `hr` 校正人工参考结构的绝对能量标尺。

### 参数量与反向传播

| 模块 | 参数量 | 是否更新 |
|---|---:|---|
| 冻结 `base` | 886,657 | 否 |
| 共享 `encoder` | 886,657 | 是，但其原输出head在 `encode()` 中不连接损失 |
| `delta_head` | 50,177 | 是 |
| `anchor_head` | 8,577 | 是 |
| 总参数 | 1,832,068 | — |
| `requires_grad=True` | 945,411 | — |
| 实际连接到损失 | 约928,770 | — |

损失和checkpoint选择：

```text
L = SmoothL1(delta, true_delta; beta=0.03)
  + 0.5 × SmoothL1(base + anchor, true_reference; beta=0.05)

selection_score = validation_delta_MAE
                + 0.25 × validation_absolute_MAE
```

## 8. 三组消融实验

### 统一对比结果

| 模型 | 测试绝对MAE | 测试ΔE MAE | 平均seed分歧 | 结论 |
|---|---:|---:|---:|---|
| Full | 0.006109 | 0.005893 | 0.009898 | 基准 |
| Single-graph | 0.009274 | 无独立ΔE头 | 0.013203 | 绝对MAE比Full高51.8% |
| No-anchor | 0.097901 | 0.006969 | 未报告 | `anchor_head`对绝对能量标尺很重要 |
| Generic-angle | 0.005012 | 0.004776 | 0.010052 | 未证明显式角类型有益 |

### Single-graph

- 只输入候选图，直接回归CHGNet代理形成能；
- 无参考图、`delta_head`和 `anchor_head`；
- 886,657个参数，全部训练；
- batch 96，learning rate `3e-5`，SmoothL1 `beta=0.05`；
- 五种子均80 epoch，最佳epoch为79/77/79/76/75；
- 共400 epoch，累计6.3分钟，峰值分配显存约1,848 MiB。

### No-anchor

- 删除 `anchor_head`和参考能量损失；
- 前向改为 `candidate = frozen_base(reference) + delta`；
- 总参数1,823,491，`requires_grad=True` 936,834，实际连接损失约920,193；
- batch 48对，encoder/head学习率分别为 `3e-5/1e-3`；
- 实际epoch为80/57/44/80/78，最佳epoch为79/45/32/72/66；
- 共339 epoch，累计26.5分钟，峰值分配显存约1,898 MiB；
- 参考结构能量MAE从Full的 `0.002592` 升到 `0.100756 eV/atom`；
- 说明 `anchor_head` 主要修正绝对标尺，对ΔE的影响较小。

### Generic-angle

- 保留角度数值，但将所有 `triplet_type` 设为同一类；
- 结构和参数量与Full相同；
- batch 48对，学习率、损失和Full相同；
- 实际epoch为80/80/80/78/62，最佳epoch为80/69/80/66/50；
- 共380 epoch，累计17.1分钟，峰值分配显存约1,898 MiB；
- Generic-angle测试误差反而略低，所以当前不能宣称显式角类型编码必要。

## 9. 面试高频问题与标准回答

### 为什么从分解能换成形成能？

分解能依赖整个相图和动态竞争相，不只由当前晶体局部结构决定。形成能的元素参考态固定，更适合学习同组成倾斜结构的能量变化。

### 为什么不用单图形成能预测后直接作差？

单图模型要同时学习eV级组成背景和meV级倾斜差异，两个绝对能量的误差也会进入差值。双图模型直接监督同组成ΔE。在当前相同划分上，Full绝对MAE比Single-graph低34.1%。

### 为什么需要 `anchor_head`？

迁移模型在DFT优化结构上训练，人工生成的零倾斜参考结构存在域偏移。`anchor_head` 只校正参考的绝对形成能标尺，`delta_head` 学习倾斜能量差。No-anchor使绝对MAE由6.1上meV/atom升到97.9上meV/atom，但ΔE MAE只由5.9升到7.0上meV/atom，与该解释一致。

### 两个AngleGNN是否都训练？

代码中有两份AngleGNN：`base` 冻结；`encoder` 可训练，并以共享参数方式先后编码候选和参考。反向传播更新 `encoder + delta_head + anchor_head`，不更新 `base`。

### 为什么ΔE头用三种组合？

`hx-hr` 保留方向性，`|hx-hr|` 表示无方向的变化幅度，`hx×hr` 表示两个局部环境的匹配程度；拼接后维度为 `3×128=384`。

### Batch 48对等于多少张图？

一对包含候选图和参考图，batch 48对每次共编码96张图；参考图在不同候选对中可重复出现。

### 不确定性怎么得到？

对同一结构用5个独立种子模型预测，取5个输出的样本标准差。它是深度集成的经验认知不确定性，不是严格置信区间。当前分歧与误差Spearman为0.451，有中等正相关。

### “留出测试”是什么？

它不参与训练、早停和checkpoint选择；但其化学组成在训练中出现，且Full与消融都已在该划分上评估。因此它是配对消融用的留出角度测试，不是全新组成盲测。

### 当前哪个消融结论是负结果？

Generic-angle在当前测试上比Full略好，所以不能声称B–O–B等显式角类型已被证明有效。这应如实报告，可能表明元素、距离和角度数值已能隐式区分大部分环境，或当前数据规模不足以体现类型编码收益。

### 最大的结果边界是什么？

1. 新倾斜标签是CHGNet代理值，不是独立DFT；
2. 测试为已见组成的角度插值，不是新组成外推；
3. 当前没有在同一标签和划分上与ALIGNN、MEGNet等成熟模型做公平对比；
4. 因此可声称“完成轻量专用方法验证”，不能声称“超越CHGNet、替代DFT或达到SOTA”。

## 10. 最适合面试的结果表述

> 我用约6万条DFT多元钙铛矿数据训练了五种子AngleGNN，再迁移到形成能任务，并利用CHGNet对1599个受控倾斜结构做代理标注。最终的双图模型用共享AngleGNN编码候选和同组成参考，直接学习细小能量差；在已见组成的留出角度上，五模型集成的ΔE MAE为5.9 meV/atom，绝对代理形成能MAE为6.1 meV/atom。Single-graph对照的绝对MAE为9.3 meV/atom，No-anchor对照为97.9 meV/atom，说明差分结构和参考校准在当前任务上有用；而显式角类型消融没有显示稳定收益，我将它作为负结果报告。所有训练都在RTX 5060 8GB上完成，双图训练的PyTorch峰值分配显存约1.9GB。这些结果目前表征的是对CHGNet代理标签的角度插值能力，不是新组成或DFT真值的最终验证。
