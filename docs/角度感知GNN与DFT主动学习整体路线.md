# 角度感知 GNN 与 DFT 主动学习整体路线

## 统一科学问题

> 角度感知晶体 GNN 能否学习多元氧化物钙钛矿中八面体倾斜与阳离子排序对稳定性的影响，并通过 DFT 主动学习发现原单起点高通量流程可能遗漏的低能多晶型？

## 研究范围

- 阴离子固定为 O；
- 使用原数据集中的 39 种阳离子；
- 研究 `AA′BB′O6` 等已有组成类型；
- 只搜索钙钛矿内部的八面体倾斜和阳离子排序；
- 不宣称找到全部晶体结构空间中的全局最低能结构。

## 项目主线

```text
现有59,708条DFT数据
→ 训练角度感知GNN
→ 与传统模型和距离GNN对照
→ 生成同组成新多晶型
→ 角度GNN筛选
→ 第一轮DFT验证
→ DFT主动学习微调
→ 第二轮筛选与DFT
→ 独立盲测
→ 计算最终分解能
```

## 统一预测目标

基础模型主目标：

```text
decomposition_energy_per_atom
```

同一组成多晶型排序目标：

```text
ΔEij = Ei − Ej
```

对于同一组成，凸包参考能固定，因此：

```text
ΔHd,i − ΔHd,j = Ei − Ej
```

同一个模型可以同时学习绝对分解能和同组成多晶型相对能量。

## 1. 建立角度感知 GNN

### 输入

节点特征：

```text
原子种类
```

边特征：

```text
原子间距离及其径向基展开
```

三体特征：

```text
j—i—k夹角
cos(θ)或角度基展开
```

重点结构信息：

- B—O—B 角；
- O—B—O 角；
- A—O—B 角；
- BO6 八面体局部畸变。

模型采用类似 ALIGNN 的思路：

```text
原子图传递距离信息
+
键线图传递角度信息
→ 晶体池化
→ 分解能
```

模型只依赖距离和夹角等旋转不变量：晶体整体旋转不改变预测，但内部八面体旋转可以改变预测。

### 建议配置

```text
hidden_dim = 128
layers = 3～4
max_neighbors = 12～16
mixed_precision = true
batch_size = 8～16
gradient_accumulation = true
```

目标是在 RTX 5060 8GB 上完成训练。

## 2. 使用基础数据预训练

使用现有 59,708 条 DFT 优化结构训练角度 GNN，并与当前距离 GNN使用完全相同的：

- 训练、验证和测试划分；
- 随机种子；
- 目标标准化；
- 早停规则；
- 评价指标。

比较：

- MAE、RMSE 和 R²；
- 稳定性 PR-AUC；
- 不同分解能区间的误差；
- 不同组成类型的误差；
- 参数量、显存和训练时间。

这一阶段回答：

> 显式加入键角，能否提高总体分解能预测能力？

基础数据每个组成只有一个结构，因此这一阶段不能单独证明模型已经学会旋转角度的独立能量贡献。

## 3. 选择多晶型研究组成

选择约 25～30 个组成：

```text
开发组成：约20个
盲测组成：5～10个
```

组成类型包括：

| 类型 | 作用 |
|---|---|
| `0.05 < ΔHd ≤ 0.10 eV/atom` | 寻找可能跨入近稳定区的材料 |
| `0.10 < ΔHd ≤ 0.15 eV/atom` | 检查较大的结构能量改善 |
| GNN 不确定性高 | 检查不确定性与结构敏感性的关系 |
| `ΔHd ≤ 0.03 eV/atom` | 稳定正对照 |
| `ΔHd > 0.20 eV/atom` | 不稳定负对照 |

同时保证元素、组成类型、容忍因子和磁性具有多样性。

开发/盲测划分必须在结构生成和DFT计算前固定，盲测组成不得参与主动学习和调参。

## 4. 生成同组成新多晶型

### 软件

- PySPuDS；
- pymatgen；
- enumlib；
- `StructureMatcher`。

### 结构变化

- 不同 Glazer 八面体倾斜；
- 不同 A/A′ 位阳离子排序；
- 不同 B/B′ 位阳离子排序；
- 必要的空间群和超胞变化。

第一批代表性倾斜：

```text

a⁰a⁰c⁻

a⁻b⁺a⁻
```

每个组成生成约 10 个去重结构：

```text
30个组成 × 10个构型 ≈ 300个候选结构
```

每条候选记录：

```text

parent_structure_id
tilt_pattern
A_site_ordering
B_site_ordering
space_group

structure_path
```

CHGNet/MACE不负责主要筛选。只有结构存在明显原子重叠、异常体积或不合理键长时，才可作为可选几何修正工具。

> 第5步起修订说明（2026-09-06）：前文保留原路线及第1—4步内容；后续目标调整为不同角度畸变结构的形成能预测，以下第5—7步为当前执行流程。

## 项目目标

输入一个确定的钙钛矿结构（元素、原子坐标和晶胞），预测这个结构在不同八面体倾斜、角度畸变下的每原子形成能，并输出五模型集成的均值与模型分歧。

形成能定义：

```text
Ef(x) = [E(x) - Σα nα μα] / N
```

其中μα为固定口径的元素参考态能量，N为原子数。最终目标是形成能，不再以分解能、凸包跨越或近稳定阈值作为主要验收指标。负形成能不等于相对于全部竞争相稳定。

模型输入完整结构；同一个平均B–O–B角可能对应不同键长、倾斜模式和能量，不能只用一个角度数预测所有结构。

## 5. 扩充多角度数据与形成能任务衔接

### 规模与覆盖

首批预算约1500个合格结构，优先考虑约100个组成、每个约15个代表构型，而不是30个组成各生成50个相近结构。具体数量随去重、几何检查和模式覆盖调整。

1500个是首批预算，不是“足够达到精准预测”的保证。原始数据提供广泛化学组成监督，新数据补充同组成内的几何能量变化；新增组成的多样性与角度覆盖都重要。

按元素、组成类型、位点组合和结构特征选择组成。每条扫描先固定阳离子排序，改变倾斜模式和幅度；本轮重点学习角度响应，不同时大规模扩展排序、缺陷与其他结构变化。

### 生成与检查

- 使用PySPuDS生成其支持的倾斜构型，连续角度扫描由周期性几何扰动程序补充；不能假定PySPuDS可直接指定任意角度。
- 检查共享氧位置、周期性连接、原子重叠、近重复和钙钛矿骨架。
- 记录母体、倾斜模式、生成幅度、实际B–O–B/O–B–O角分布、键长及体积。
- 若扰动伴随键长变化，明确记录，不将全部能量变化解释为纯角度效应。

按约化组成固定训练、验证、独立测试集合，母体及其所有变体属于同一集合。检查原始59,708条基础训练数据的组成重合；测试组成也必须从新的形成能基础训练中排除。原研究组成已被选样或查看的历史应记录，新的独立测试优先使用未参与开发的组成。

输出：合格候选CIF、结构清单、固定组成划分。

## 6. CHGNet标注与五模型主动学习

### 先将模型目标切换为形成能

使用原数据中的 `formation_energy_per_atom`，核对单位、来源与结构对应关系。以原分解能模型表示层初始化、重新初始化形成能预测头，并仅用新训练集计算形成能标准化量。先完成一个种子试运行，再完成五模型。

不能直接改名旧输出，也不能仅靠少量母体锚点完成形成能目标迁移。

### 保留角度进行标注

对候选结构x及其对应的原始母体x0，用同一版本CHGNet进行单点计算，固定原子坐标和晶胞。主数据不做自由弛豫，以免不同角度收敛到同一结构。

每原子代理形成能为：

```text
Ef_proxy(x)
= Ef_dataset(x0)
+ [e_CHGNet(x) - e_CHGNet(x0)]
```

原始母体必须与数据集形成能标签严格对应；两项CHGNet能量也必须使用对应输入几何。母体自身的代理形成能应回到原始标签。

同组成内元素参考项在能量差中抵消，但CHGNet对DFT能量差的近似误差仍存在。数据字段分别保存原始形成能、CHGNet单点能量、代理形成能、结构ID及标签来源，新增代理值不标为DFT真值。

### 训练与迭代

保留原始形成能训练样本，加入角度代理样本，采用联合损失：

```text
L = L_原始形成能 + λ × L_角度代理形成能
```

同组成成对能量差损失作为可选增强项，根据验证效果决定是否加入；它与代理标签来源相同，不算额外独立标签。低学习率、早停和数据混合比例在验证集上确定。

循环执行：

```text
生成或扩充多角度候选数据
→ 形成能五模型评分
→ 按模型分歧与角度/组成多样性选样
→ CHGNet单点标注
→ 加入训练并更新五模型
→ 在固定验证集评估误差、排序和不确定性
→ 未达标：按诊断补充训练组成/角度数据，回到选样标注
→ 达标：冻结方案，进行独立测试验收与交付
```

初始样本覆盖训练组成及代表角度，后续补充高分歧、覆盖不足和变化明显的区域，不只选最低能点。

设同预算随机采样对照，在约300、600、1000及1500个新增训练标签处记录学习曲线；这些数量是可调整检查点，若1500个预算含验证/测试样本，训练检查点按实际池大小相应缩减。验证和测试标签单独计数，不进入训练预算。重复采样实验以区分策略效果与随机波动。

候选池较小时可一次性完成CHGNet标注后隐藏未查询标签，进行离线主动学习；此时明确报告模拟标签预算，不声称这些已算标签带来实际计算节省。

### 是否继续加数据

目标是循环至达到下列验收要求，不以固定样本数或轮数作为完成标志。每轮所说的“测试”使用验证集；独立测试集不参与早停、权重选择、采样决策或阈值调整。

- 数据量增加后验证误差仍明显降低：继续扩充，优先补缺少的组成和角度区域。
- 连续两轮改善小于重复实验波动：先检查标签、覆盖及模型，再决定停止或修改。
- 原始形成能预测明显退化：调整数据混合和训练权重。
- 主动采样不优于随机采样：如实报告，可采用覆盖采样或全量代理训练完成模型。

不规定“1500个或三轮结束就一定微调好了”。扩大到首批预算之外前，报告学习曲线、预计资源和拟增加规模。连续两轮停滞是诊断触发条件，不等于项目达标；诊断后修改数据或训练方法再评估。若资源或标签精度不足以支持目标，如实记录未达标及原因，不降低阈值来宣称完成。

### 每轮验收指标

以下为暂定工程目标，尚非实测结果。先根据首批开发数据的实际角度能差尺度确认适用性，并在正式循环前固定；例如主要能差仅2—5 meV/atom时，10 meV/atom不足以支持精细区分，需要收紧目标。

| 指标 | 暂定合格要求 | 作用 |
|---|---|---|
| 同组成成对能量差MAE | ≤0.01 eV/atom（10 meV/atom） | 主指标：角度变化对应的能量差是否准确 |
| 原始DFT数据集形成能MAE | 相比形成能基础模型恶化≤5% | 保留原始形成能预测能力 |
| 最低能候选选择的平均regret | ≤0.01 eV/atom | 选中结构与已标注候选最低能结构的差距 |

统一使用五模型集成均值计算上述预测指标。同组成成对误差定义为绝对值|(预测Ef_i−预测Ef_j)−(参考Ef_i−参考Ef_j)|，先在各组成内对唯一结构对取平均，再对组成平均，避免结构多的组成支配指标；regret也按组成平均。形成能退化率在同一评价集合比较微调模型和形成能基础模型，不能使用旧分解能模型作基准。

同时报告绝对角度代理形成能MAE、误差分位数和分组成结果；成对误差达标不代表绝对形成能已达到10 meV/atom精度。相对基础模型退化≤5%只检验保持能力，若基础模型本身精度不足，仍不能据此宣称绝对形成能精准。

### 不确定性如何参与决策

五模型标准差表示模型分歧，不单独作为准确性合格线。每轮检查分歧与绝对误差的相关性、不同分歧区间的误差及风险—覆盖率曲线。

若要用不确定性判断角度能差可信度，应先让每个模型分别计算Ef_i−Ef_j，再对五个差值求标准差；不能把两个结构的标准差简单相加。

在验证集上选择分歧阈值，使被接受子集满足相应误差要求，并报告其覆盖率；覆盖率需求随实际用途在循环前固定，不能只接受极少数样本来宣称整体可靠。阈值在独立测试前冻结，不预先假定标准差小于0.01就一定准确。

- 误差未达标且分歧能识别高误差区域：优先在训练候选池补充对应角度和组成类型。
- 误差高但分歧低：检查共同模型偏差和标签，增加多样性采样，不只按分歧选样。
- 误差达标但分歧无法识别风险：能量预测与不确定性功能分别报告，继续校准或明确不确定性尚不可用。
- 能量指标和预先固定的不确定性使用要求均满足：进入独立验收。

所有CHGNet角度标签上的达标结论限定为代理精度。各轮不得把验证结构加入训练；可以按验证发现的薄弱类型生成新的训练组成候选。

输出：五个形成能模型、逐轮标签清单、学习曲线、显存/耗时记录。

## 7. 独立测试与最终交付

固定模型后评估独立测试集，分别报告：

使用第6步固定的指标及阈值验收。若独立测试未达标，记录本次失败；若据此修改模型，该测试集转为开发资料，下一次最终验收须使用新的未触碰测试组成，不能反复调到原测试集过线。

| 指标 | 说明 |
|---|---|
| 原始形成能MAE/RMSE/R² | 对公开数据集形成能标签的预测能力 |
| 角度代理形成能MAE | 对CHGNet辅助标签的拟合，不能称为新DFT精度 |
| 同组成直接成对能量差MAE | 对畸变引起的能量变化是否准确 |
| 角度—能量曲线、排序和regret | 能否识别已测试候选中的低能结构 |
| 误差与五模型分歧的关系 | 不确定性是否有选样依据 |
| 主动采样与随机采样学习曲线 | 同预算下是否有稳定收益 |

区分已见组成的新角度和未见组成的泛化。未见组成不能只由新的material_id定义。

可用程度由误差和使用场景判断：例如需要分辨10 meV/atom的结构差异，30 meV/atom的成对误差就不足以支持可靠排序。这个例子不是预先承诺的验收阈值。仅报告在测试覆盖范围内证实的能力，不扩展为任意钙钛矿、任意畸变均准确。

本轮交付不以新增VASP计算为前提。若未来有适用公开数据或计算资源，再增加独立DFT角度验证；缺少该证据时，结论为“CHGNet辅助的畸变形成能估计”，不能宣称DFT级精准预测。

最终交付：

1. 五个明确以形成能为目标的AngleGNN checkpoint及配置。
2. 输入CIF、输出形成能均值和模型分歧的推理脚本。
3. 带实际角度、结构对应关系和标签来源的数据集。
4. 测试结果、主动学习对照、资源记录与复现说明MD。
