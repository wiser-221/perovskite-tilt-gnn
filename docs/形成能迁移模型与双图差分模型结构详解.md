# 形成能迁移模型与双图差分模型结构详解

本文只解析 `transfer_learning` 中最终真正使用的两个模型：

1. `base_models.pt` 中的形成能迁移模型；
2. `final_models.pt` 中的候选—参考双图差分模型。

两者底层都使用 `project/models.py` 的 `AngleGNN`。本文重点解释它们怎样从原始 AngleGNN 迁移、矩阵如何流动、哪些参数会训练、损失怎样计算，以及最后输出的数值究竟是什么。

> 当前模型有五个随机种子：42、123、2026、3407、7777。下面先讲单个 seed；五模型集成只是把五个单模型的结果求均值和标准差。

## 1. 两个模型之间的关系

```text
原分解能 AngleGNN checkpoint
          │
          │ 保留图编码参数，重新初始化输出 head
          ▼
形成能迁移模型 AngleGNN
base_models.pt
          │
          ├──────────复制1：base，完全冻结
          │
          └──────────复制2：encoder，继续训练
                         │
候选图 x ────────────────┤
参考图 r ────────────────┘
          │
          ▼
双图差分模型 DualAngleGNN
final_models.pt
```

第一个模型回答：

```text
只给一个晶体图，它的形成能大约是多少？
```

第二个模型回答：

```text
给一个畸变候选结构 x，再给同组成参考结构 r：
参考结构的形成能是多少？
候选相对参考改变了多少能量？
两者相加后，候选结构的形成能是多少？
```

## 2. 公共符号和实际超参数

```text
B   = 一个 batch 中的晶体对数量
Nx  = batch 中所有候选图的原子总数
Nr  = batch 中所有参考图的原子总数
Ex  = 候选图的有向边总数
Er  = 参考图的有向边总数
Tx  = 候选图的三体角总数
Tr  = 参考图的三体角总数

H = hidden_dim = 128
R = radial_dim = 32
A = angle_dim = 16
L = AngleLayer 数量 = 4
cutoff = 5.0 Å
angle_scope = typed
```

形成能训练的主要配置：

```text
batch_size       = 96
最大 epoch       = 40
early-stop patience = 8
learning rate    = 3×10⁻⁴
```

双图训练的主要配置：

```text
batch_size          = 48 对图
最大 epoch          = 80
early-stop patience = 12
encoder learning rate = 3×10⁻⁵
head learning rate    = 1×10⁻³
anchor loss weight    = 0.5
```

## 3. 公共的 AngleGNN 编码器

两个模型内部的每个 AngleGNN 都采用同一条编码路线。完整的 AngleLayer 三体消息过程可参见《AngleGNN模型结构与矩阵变化详解》，这里给出后续理解双图所必需的矩阵尺寸。

### 3.1 单个图 batch 的输入

```text
z                    [N]       原子序数
edge_index           [2,E]     有向边连接
distance             [E]       边距离
triplet_edge_index   [2,T]     组成每个角的两条边
triplet_cosine       [T]       角余弦
triplet_type         [T]       B—O—B、O—B—O等角类型
batch                [N]       每个原子属于哪个晶体
```

### 3.2 初始节点和边矩阵

```text
z [N]
  ↓ Embedding(119,128)
nodes [N,128]

distance [E]
  ↓ 32个高斯径向基
radial [E,32]

[nodes_center, nodes_neighbor, radial]
[E,128] + [E,128] + [E,32]
  ↓ 拼接
[E,288]
  ↓ MLP(288 → 128 → 128)
edges [E,128]
```

### 3.3 三体角矩阵

```text
triplet_cosine [T]
  ↓ 16个高斯角度基
angle_basis [T,16]

triplet_type [T]
  ↓ Embedding(4,128)
type_features [T,128]
```

每个三体角选择两条边 `Fj`、`Fk`：

```text
[Fj + Fk, |Fj - Fk|, angle_basis, type_features]
[T,128] + [T,128] + [T,16] + [T,128]
  ↓ 拼接
[T,400]
  ↓ MLP(400 → 128 → 128)
triplet_message [T,128]
```

消息先平均聚合到边，再平均聚合到节点。每个 AngleLayer 都保持：

```text
nodes [N,128] → [N,128]
edges [E,128] → [E,128]
```

四层之后，按晶体对节点求平均：

```text
nodes [N,128]
  ↓ 按 batch 分组平均池化
crystal_features h [B,128]
```

`AngleGNN.encode(graph)` 到这里结束；`AngleGNN.forward(graph)` 还会继续执行：

```text
h [B,128]
  ↓ Linear(128 → 128)
  ↓ SiLU
  ↓ Linear(128 → 1)
normalized_prediction [B]
```

## 4. 模型一：形成能迁移模型

对应代码：`transfer_learning/train_formation.py`。

对应权重：`transfer_learning/base_models.pt`。

### 4.1 “迁移”具体迁移了什么

训练不会从随机模型开始，而是读取此前五个角度感知分解能模型：

```text
outputs/angle_ensemble/seed_<seed>/best_model.pt
```

它保留以下已经学到的参数：

```text
元素 embedding
角类型 embedding
初始边 MLP
4个 AngleLayer
各层 LayerNorm
```

原模型最后的输出 head 学的是旧目标，因此两个 Linear 层都调用 `reset_parameters()` 重新随机初始化：

```text
旧图编码器参数 ──保留──► 形成能图编码器初值
旧输出 head     ──丢弃──► 新随机输出 head
```

随后不是只训练新 head，而是对整个 AngleGNN 做端到端微调。因此 embedding、4个消息传递层、LayerNorm和新 head 都会更新。

### 4.2 训练标签

形成能迁移模型直接读取原始数据集字段：

```text
formation_energy_per_atom
```

单位为 `eV/atom`，checkpoint 中标记为：

```text
target       = formation_energy_per_atom
label_source = dataset_DFT
```

这里的标签是原数据集DFT形成能，不是CHGNet代理标签。

实际划分为：

```text
训练：51923条
验证：4217条
测试：3568条
```

划分按约化组成隔离，同一组成不会同时出现在形成能训练和验证/测试中。

### 4.3 标签标准化

五个 seed 共用训练集计算出的：

```text
μ = -2.7236380143 eV/atom
σ =  0.5077051269 eV/atom
```

真实标签先变为：

```text
y_norm = (y - μ) / σ
```

模型训练时输出无量纲的 `ŷ_norm`。推理时再恢复：

```text
ŷ = ŷ_norm × σ + μ
```

最终 `ŷ` 才是 `eV/atom`。

### 4.4 前向矩阵路线

```text
单个晶体图 GraphData
  ↓ AngleGNN.encode
h [B,128]
  ↓ MLP head(128 → 128 → 1)
ŷ_norm [B]
  ↓ ×σ + μ
形成能 ŷ [B]，单位 eV/atom
```

### 4.5 损失函数

使用 Smooth L1，而不是直接使用MAE：

```text
Lformation = SmoothL1(ŷ_norm, y_norm; beta=0.1)
```

误差较小时它像平方误差，便于稳定优化；误差较大时接近绝对误差，降低异常点的影响。

优化设置：

```text
AdamW
learning rate = 3×10⁻⁴
weight decay  = 1×10⁻⁵
gradient clipping = 5
ReduceLROnPlateau：连续3轮无改善后学习率×0.5
early stopping：连续8轮无有效改善后停止
```

最佳模型按原始单位的验证形成能 MAE 选择。

### 4.6 参数量

单个形成能模型的真实 `nn.Parameter` 数量为 `886,657`：

|模块|参数量|是否训练|
|---|---:|---|
|元素 Embedding(119,128)|15,232|是，padding行不接收普通梯度|
|角类型 Embedding(4,128)|512|是|
|初始边 MLP|53,504|是|
|4个 AngleLayer|800,768|是|
|形成能输出 head|16,641|是，迁移开始时重新初始化|
|合计|886,657|全部参与形成能微调|

高斯距离基32个中心和角度基16个中心合计48个数存为 buffer，不是训练参数。

### 4.7 实际五个 checkpoint

|seed|最佳 epoch|验证形成能 MAE (eV/atom)|
|---:|---:|---:|
|42|36|0.016325|
|123|38|0.017139|
|2026|25|0.018592|
|3407|39|0.017438|
|7777|26|0.018537|

这些值来自 `base_models.pt` 内保存的 `best_epoch` 和 `selection_score`。

## 5. 模型二：候选—参考双图差分模型

对应代码：`transfer_learning/train_delta.py` 中的 `DualAngleGNN`。

对应权重：`transfer_learning/final_models.pt`。

### 5.1 为什么要输入两张图

若只输入候选结构，模型既要学组成决定的巨大绝对能量差，也要学角度畸变造成的较小能量差。后者容易被前者淹没。

双图模型为每个候选结构 `x` 配一个同组成参考结构 `r`：

```text
x = 某个角度畸变的候选结构
r = 同组成的立方参考结构
```

99个组成使用立方参考；1个组成的立方结构与母体去重后不存在，使用该组成最小倾斜幅度的生成结构。

这样模型直接学习：

```text
ΔE = E(x) - E(r)
```

同组成的主要化学基线在相减时抵消，学习重点转向结构畸变造成的能量变化。

### 5.2 双图模型包含四个部分

```text
DualAngleGNN
├── base         一个完整 AngleGNN，冻结
├── encoder      一个完整 AngleGNN，继续训练；实际调用 encode()
├── delta_head   把候选—参考特征变成相对能量
└── anchor_head  修正参考结构的形成能基线
```

`base` 和 `encoder` 在初始化时都复制同一个 seed 的形成能迁移模型参数，但之后职责不同：

```text
base    ：保留原DFT形成能知识，不更新
encoder ：针对CHGNet角度能量差继续学习
```

### 5.3 两张图分别编码

候选图和参考图经过同一个共享权重的 `encoder`：

```text
候选图 x：
z_x [Nx]、edge_x [2,Ex]、triplet_x [2,Tx]
  ↓ 同一个 encoder.encode
hx [B,128]

参考图 r：
z_r [Nr]、edge_r [2,Er]、triplet_r [2,Tr]
  ↓ 同一个 encoder.encode
hr [B,128]
```

这里不是两个独立编码器。候选和参考调用同一个对象，所以使用完全相同的 embedding、AngleLayer和LayerNorm参数。

### 5.4 构造384维比较向量

模型对 `hx` 和 `hr` 构造三种关系：

```text
hx - hr       [B,128]   有方向差异：候选相对参考怎样变化
|hx - hr|     [B,128]   无方向差异：变化幅度有多大
hx × hr       [B,128]   对应维度的相互作用
```

沿最后一维拼接：

```text
z = [hx-hr, |hx-hr|, hx×hr]

[B,128] + [B,128] + [B,128]
             ↓
          [B,384]
```

### 5.5 delta_head：预测相对参考的能量变化

```text
z [B,384]
  ↓ LayerNorm(384)
  ↓ Linear(384 → 128)
  ↓ SiLU
  ↓ Linear(128 → 1)
raw_delta [B]
```

代码还计算同一个 head 在全零向量上的输出：

```text
delta_norm = delta_head(z) - delta_head(zeros_like(z))
```

作用是消除 `delta_head` 对全零比较向量的常数偏置。

必须准确理解：因为 `z` 中包含 `hx×hr`，即使 `x=r`，这一部分通常也是 `h²` 而不是零。因此这项相减**不能从数学上保证**任意相同输入都有 `delta=0`；它只保证输入比较向量真为全零时输出为零。实际参考关系仍主要靠训练标签学习。

训练初始时，`delta_head` 最后一层 Linear 的权重和偏置都设为0，所以：

```text
训练开始时 delta_norm = 0
```

这让模型从“不修改形成能基线”开始逐步学习畸变修正。

### 5.6 base：给出参考结构形成能基线

参考图 `r` 还经过冻结的形成能模型：

```text
r
  ↓ frozen base.forward
base_norm [B]
```

注意 `base` 只处理参考图，不直接处理候选图。它提供形成能坐标系的起点。

### 5.7 anchor_head：校准参考结构

可训练参考特征 `hr` 进入：

```text
hr [B,128]
  ↓ LayerNorm(128)
  ↓ Linear(128 → 64)
  ↓ SiLU
  ↓ Linear(64 → 1)
anchor_norm [B]
```

`anchor_head` 最后一层也以全零权重和偏置开始，所以训练开始时不修改冻结基线。

它的作用不是预测候选—参考差，而是校准人工生成参考结构的绝对形成能：

```text
reference_norm = base_norm + anchor_norm
```

### 5.8 最终前向公式和矩阵

归一化空间中的最终输出：

```text
candidate_norm = base_norm + anchor_norm + delta_norm
```

矩阵尺寸：

```text
base_norm   [B]
anchor_norm [B]
delta_norm  [B]
      ↓ 逐元素相加
candidate_norm [B]
```

恢复到物理单位：

```text
Êformation(x) = candidate_norm × σ + μ

ΔÊ(x,r) = delta_norm × σ
```

差分只乘 `σ`，不加 `μ`，因为两个能量相减时均值会抵消。

整个前向过程可压缩成：

```text
候选图 x ──► shared encoder.encode ──► hx [B,128] ─┐
                                                    ├─► z [B,384] ─► delta_head ─► delta_norm
参考图 r ──► shared encoder.encode ──► hr [B,128] ─┘
                                      │
                                      └──────────────► anchor_head ─► anchor_norm

参考图 r ──► frozen base.forward ───────────────────► base_norm

base_norm + anchor_norm + delta_norm
                 │
                 ▼
          candidate_norm [B]
                 │ ×σ + μ
                 ▼
      候选形成能 [B]，eV/atom
```

## 6. 双图模型的两个训练目标

### 6.1 差分目标

数据库保存CHGNet对固定几何结构的单点能量。对候选 `x` 和参考 `r`：

```text
d = E_CHGNet(x) - E_CHGNet(r)       单位 eV/atom
d_norm = d / σ
```

差分损失为：

```text
Ldelta = SmoothL1(delta_norm, d/σ; beta=0.03)
```

这是主要任务：让模型学会角度畸变相对参考结构改变了多少能量。

### 6.2 参考锚定目标

代理形成能定义为：

```text
Dproxy(i)
= DDFT(parent)
  + [ECHGNet(i) - ECHGNet(parent)]
```

令参考结构的代理形成能为 `yr`，则：

```text
yr_norm = (yr - μ) / σ
```

锚定损失为：

```text
Lanchor = SmoothL1(base_norm + anchor_norm, yr_norm; beta=0.05)
```

它防止模型只学会相对能量差，却不知道整条能量曲线应该放在绝对形成能坐标轴的什么位置。

### 6.3 总损失

```text
L = Ldelta + 0.5 × Lanchor
```

直观理解：

```text
Ldelta 负责曲线形状：不同角度之间高低差多少
Lanchor 负责曲线位置：整条曲线位于多少 eV/atom
```

### 6.4 最佳 checkpoint 的选择

每轮在验证集计算：

```text
delta_MAE    = |预测ΔE - 真实ΔE|的平均值
absolute_MAE = |预测代理形成能 - 代理标签|的平均值

selection_score = delta_MAE + 0.25 × absolute_MAE
```

训练以较小的 `selection_score` 为优；改善不足 `10⁻⁵` 不覆盖 checkpoint，连续12轮没有有效改善则早停。

## 7. 双图模型哪些参数训练，哪些冻结

单个双图模型共有 `1,832,068` 个 `nn.Parameter`：

|模块|参数量|`requires_grad`|是否真正收到梯度|
|---|---:|---|---|
|frozen base AngleGNN|886,657|否|否|
|shared encoder AngleGNN|886,657|是|除其旧输出head外，是|
|delta_head|50,177|是|是|
|anchor_head|8,577|是|是|
|合计|1,832,068|945,411被声明可训练|约928,770连接到当前损失|

为什么 encoder 的旧输出 head 没有梯度：

```text
encoder 是完整 AngleGNN，内部仍保存原来的 head；
但 DualAngleGNN 调用 encoder.encode(x)，而不是 encoder.forward(x)；
所以计算图在128维池化特征处结束，永远不经过 encoder.head。
```

这16,641个参数被保存在 checkpoint，也被放入优化器参数组，但梯度始终为 `None`，不会被AdamW更新。它们不影响双图输出，只是当前实现中可以进一步清理的冗余参数。

两组学习率：

```text
encoder                   3×10⁻⁵
delta_head + anchor_head  1×10⁻³
```

新 head 学习率约为编码器的33.3倍，含义是：谨慎调整已经学好的图表示，快速学习新的差分映射。

## 8. 两个模型的直接对照

|项目|形成能迁移模型|双图差分模型|
|---|---|---|
|输入|一张晶体图|候选图 + 同组成参考图|
|主要监督|原数据集DFT形成能|CHGNet候选—参考能量差|
|绝对能量锚点|DFT形成能标签本身|参考结构代理形成能|
|图编码器调用|`AngleGNN.forward()`|`encoder.encode()`两次，共享权重|
|输出|单结构形成能|候选形成能 + 相对参考ΔE|
|参数量/seed|886,657|1,832,068|
|冻结参数|0|886,657|
|主要用途|提供可信的形成能基线|学习已知组成内的角度能量曲线|

## 9. 五模型集成和不确定性

五个 seed 分别训练，推理同一对结构得到：

```text
Ê42, Ê123, Ê2026, Ê3407, Ê7777
```

最终形成能：

```text
Êensemble = mean(Êseed)
```

模型分歧：

```text
uE = sample_std(Êseed, ddof=1)
```

差分同理：

```text
ΔÊensemble = mean(ΔÊseed)
uΔ = sample_std(ΔÊseed, ddof=1)
```

这里的标准差表示五个模型之间的分歧，不自动等于严格的统计置信区间。它必须通过“不确定性是否与真实误差正相关”等指标校准。本项目封存测试上的差分不确定性—绝对误差 Spearman 约为0.451。

## 10. 推理时为什么必须提供参考CIF

形成能基础模型可以只输入一个CIF：

```text
train_formation.py infer --cif candidate.cif
```

最终双图模型必须再提供同组成参考结构：

```text
train_formation.py infer \
  --cif candidate.cif \
  --reference-cif cubic_reference.cif
```

否则无法构造 `hx-hr`、`|hx-hr|` 和 `hx×hr`，也就无法预测畸变能量差。

输出包括：

```text
formation_ev_atom             五模型平均形成能
ensemble_std_ev_atom          形成能模型分歧
delta_from_reference_ev_atom  相对参考的平均能量差
delta_ensemble_std_ev_atom    差分模型分歧
seeds                         五个单模型形成能输出
```

## 11. 最容易混淆的四点

### 11.1 第一个模型是迁移学习，但不是只训练MLP头

只有开始时重新初始化输出 head；正式形成能训练会更新整个 AngleGNN。

### 11.2 双图不是把两张图在原子维直接拼起来

两张图先独立经过共享编码器并各自池化成 `[B,128]`，然后才在晶体特征层拼成 `[B,384]`。

### 11.3 最终形成能不是纯CHGNet输出

绝对坐标来自原数据集DFT形成能训练的冻结基线；角度差来自CHGNet代理监督。准确标签来源是：

```text
dataset_DFT_anchor_plus_CHGNet_delta
```

因此最终测试MAE是相对代理标签的误差，不能表述成相对真实DFT的角度形成能误差。

### 11.4 最终模型的适用范围是已知组成的角度插值

训练、验证、测试的候选ID和 `(组成,模式,角度)` 不重叠，但100个组成有意共享。当前结果证明模型能预测这些已知组成的未见角度，不证明能外推到任意新钙钛矿组成。

## 12. 一句话总结

```text
形成能迁移模型：
把原分解能AngleGNN的图表示迁移到DFT形成能任务，得到单结构绝对能量基线。

双图差分模型：
冻结该基线，同时用共享AngleGNN比较候选与同组成参考图，
学习CHGNet监督的角度能量差，再把“基线 + 锚点校准 + 差分”组合成候选形成能。
```
