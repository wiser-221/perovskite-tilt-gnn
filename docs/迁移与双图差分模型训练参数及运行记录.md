# 形成能迁移与双图差分模型：训练参数及运行记录

本文汇总 `transfer_learning` 中形成能迁移模型和双图差分模型的训练配置与实际运行数据。数据来自配置文件、五个 seed 的 checkpoint、逐 epoch 事件及 GPU 监控数据库。

> 本记录只统计这两个阶段，不包括此前原始分解能 AngleGNN 的预训练。角度结构标签为 CHGNet 代理标签，不是新计算的 DFT 标签。

## 1. 形成能迁移模型

### 训练设置

|项目|设置或实测值|
|---|---:|
|随机种子|42、123、2026、3407、7777|
|训练集 / 验证集|51,923 / 4,217 个结构|
|Batch size|96 个结构|
|Epoch 上限|40|
|早停耐心值|8 轮|
|优化器|AdamW|
|初始学习率|0.0003|
|权重衰减|0.00001|
|混合精度|BF16|
|CPU线程|2|

训练标签是原始数据集的 `formation_energy_per_atom`。每个 seed 都从已有分解能 AngleGNN 权重初始化，重置输出 head，然后对整个 AngleGNN 进行形成能微调。

### 每个 seed 的实际训练轮数

|Seed|实际训练 Epoch|保存 checkpoint 的最佳 Epoch|最佳验证形成能 MAE (eV/atom)|
|---:|---:|---:|---:|
|42|40|36|0.016325|
|123|40|38|0.017139|
|2026|33|25|0.018592|
|3407|40|39|0.017438|
|7777|34|26|0.018537|

五个 seed 共记录187个 epoch。逐 epoch 耗时累计约 **10,667秒（2小时57分47秒）**；从第一轮开始到该阶段完成，记录的墙钟时间约 **2小时59分40秒**。单个 epoch 平均约57秒。

### 显卡与显存

- 显卡：NVIDIA GeForce RTX 5060，监控报告总显存8,151 MiB。
- 训练期 GPU 利用率监控共1,056个样本：平均约42.3%，最低1%，最高59%。
- `nvidia-smi`整卡显存占用平均约3,668 MiB，峰值约3,862 MiB；监控期间最高温度62°C。
- PyTorch训练事件记录的模型峰值分配显存约1,157 MiB。该数值只代表PyTorch分配量，与`nvidia-smi`整卡占用口径不同。

### 参数量

单个 AngleGNN 有 **886,657个可训练参数**。形成能迁移训练中这些参数都参与微调，包括重新初始化后的形成能输出 head。五个 seed 是五份独立模型，不是共享一套参数。

## 2. 双图差分模型

### 训练设置

|项目|设置或实测值|
|---|---:|
|随机种子|42、123、2026、3407、7777|
|训练 / 验证 / 测试候选|800 / 200 / 400 个|
|Batch size|48对候选—参考结构（每批96张图）|
|Epoch 上限|80|
|早停耐心值|12轮|
|优化器|AdamW|
|编码器学习率|0.00003|
|差分头、锚点头学习率|0.001|
|权重衰减|0.00001|
|梯度裁剪|5|
|混合精度|BF16|
|锚点损失权重|0.5|

### 每个 seed 的实际训练轮数

|Seed|实际训练 Epoch|保存 checkpoint 的最佳 Epoch|
|---:|---:|---:|
|42|76|64|
|123|80|68|
|2026|68|56|
|3407|74|62|
|7777|80|78|

五个 seed 共记录378个 epoch。逐 epoch 耗时累计约 **976秒（16分16秒）**；从第一轮开始到最后一个 seed 完成，墙钟时间约 **16分17秒**。稳定阶段单个 epoch 约2.5—2.7秒。

### 显卡与显存

- 显卡：NVIDIA GeForce RTX 5060。
- PyTorch训练日志记录到的峰值分配显存约 **1,898 MiB**。
- 双图训练发生期间没有保存 GPU 利用率采样，因此没有可核验的平均或峰值利用率数字。

### 参数量

单个双图模型共有 **1,832,068个参数**：

|组成|参数量|状态|
|---|---:|---|
|冻结的形成能基线 `base`|886,657|冻结|
|共享图编码器 `encoder`|886,657|可训练；其中原输出 head 未被前向调用|
|差分头 `delta_head`|50,177|可训练|
|锚点头 `anchor_head`|8,577|可训练|

按 `requires_grad` 统计，可训练参数为945,411个。由于 `encoder` 只调用 `encode()`，其16,641个输出 head 参数没有梯度；真正连到训练损失的参数约 **928,770个**。

## 3. 两个阶段并列比较

|指标|形成能迁移模型|双图差分模型|
|---|---:|---:|
|每个 seed 参数量|886,657|1,832,068|

|五 seed epoch 耗时合计|约2小时57分47秒|约16分16秒|
|峰值 PyTorch 分配显存|约1,157 MiB|约1,898 MiB|
|GPU 利用率记录|平均42.3%，峰值59%|未记录|

## 4. 复核来源

- 配置：`transfer_learning/config.json`
- 形成能迁移训练代码：`transfer_learning/train_formation.py`
- 双图差分训练代码：`transfer_learning/train_delta.py`
- 形成能迁移模型 checkpoint：`transfer_learning/base_models.pt`
- 双图差分模型 checkpoint：`transfer_learning/final_models.pt`
- 逐 epoch 记录及 GPU 监控：`transfer_learning/results.sqlite`
- 双图逐 epoch 导出：`transfer_learning/training_history.csv`

参数量中的总量来自实际实例化的 PyTorch 模型；checkpoint 的 `state_dict` 还包含固定的高斯基中心等 buffer，因此直接累加 checkpoint 张量元素会比可训练参数量略大。
