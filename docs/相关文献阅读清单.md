# 相关文献阅读清单

## 1. 迁移学习最直接的参考

### Transfer Learning for Materials Informatics Using Crystal Graph Convolutional Neural Network

这篇与Step 5最接近：先在大数据材料性质上预训练CGCNN，再更换任务并微调整个网络，研究迁移是否优于随机初始化。它也指出，源任务与目标任务相关性越强，迁移通常越有效。

- 期刊：*Computational Materials Science*，2021
- 链接：https://www.sciencedirect.com/science/article/pii/S0927025621000392

重点看：

- 如何保留预训练权重；
- 如何替换输出层；
- 微调与从零训练的对照；
- 不同训练数据量下迁移学习的收益。

## 2. 结构GNN深度迁移学习

### Structure-Aware Graph Neural Network Based Deep Transfer Learning Framework for Enhanced Predictive Analytics on Diverse Materials Datasets

该工作使用形成能预训练的ALIGNN进行多种材料性质迁移，并对比了：

```text
从零训练
全模型微调
冻结编码器作为特征提取器
```

它发现小数据任务中，冻结编码器有时比全模型微调更稳定。这对判断Step 5是否应该更新所有层具有直接参考价值。

- 期刊：*npj Computational Materials*，2023
- 链接：https://www.nature.com/articles/s41524-023-01185-3

## 3. AngleGNN结构最接近的参考

### Atomistic Line Graph Neural Network for Improved Materials Property Predictions

ALIGNN同时在以下两种图上传递消息：

```text
原子—键图
键—角线图
```

它显式使用键长和键角。当前AngleGNN中“三体角→边→节点”的设计与它最接近。

- 期刊：*npj Computational Materials*，2021
- 链接：https://www.nature.com/articles/s41524-021-00650-1

重点看：

- 为什么要建立线图；
- 角信息如何更新边表示；
- 边信息如何更新原子表示；
- 角度消融实验；
- 形成能预测结果。

## 4. CGCNN基础论文

### Crystal Graph Convolutional Neural Networks for an Accurate and Interpretable Prediction of Material Properties

这是晶体图神经网络的经典起点，提出从原子、键和周期晶体结构直接预测形成能等性质。

- 期刊：*Physical Review Letters*，2018
- 链接：https://gg.mit.edu/wp-content/uploads/2018/06/PhysRevLett.120.145301-2.pdf

重点看：

- 为什么晶体可以表示成图；
- 原子节点与周期邻居边如何构造；
- 图池化为什么能得到晶体级性质；
- 形成能预测任务的基本设计。

## 5. 项目使用的原始钙钛矿数据集

### Dataset of Theoretical Multinary Perovskite Oxides

这是当前项目数据的直接来源，包含66,516条多元氧化物记录，同时提供：

```text
形成能
分解能
A/B位元素
氧化态
容忍因子
DFT优化结构
```

论文明确区分：

- 形成能：相对于元素参考态；
- 分解能：相对于Materials Project中的所有竞争相。

- 期刊：*Scientific Data*，2023
- 链接：https://www.nature.com/articles/s41597-023-02127-w

这篇必须仔细阅读，因为面试官可能会问：

- 数据如何产生；
- SPuDS起始结构是什么；
- DFT进行了什么优化；
- 形成能和分解能如何定义；
- 为什么原数据有66,516条，而项目实际使用59,708条。

## 6. CHGNet原始论文

### CHGNet as a Pretrained Universal Neural Network Potential for Charge-Informed Atomistic Modelling

CHGNet在超过150万个Materials Project轨迹结构上训练，同时学习：

```text
能量
原子力
应力
磁矩
```

这是Step 6使用CHGNet生成角度代理标签时必须引用的论文。

- 期刊：*Nature Machine Intelligence*，2023
- 链接：https://doi.org/10.1038/s42256-023-00716-3

重点看：

- CHGNet训练数据来源；
- 能量、力、应力和磁矩的联合训练；
- 单点能与结构弛豫；
- GGA/GGA+U及Materials Project能量口径；
- CHGNet在非平衡结构上的适用范围。

## 7. 补充：通用三体机器学习势

### A Universal Graph Deep Learning Interatomic Potential for the Periodic Table

M3GNet同样使用三体相互作用和Materials Project弛豫轨迹训练，可用于理解“性质GNN”和“机器学习势”的区别。

- 期刊：*Nature Computational Science*，2022
- 链接：https://www.nature.com/articles/s43588-022-00349-3

1. 原始钙钛矿数据集；
2. CGCNN；

4. CGCNN迁移学习；
